Moduł avoraiser.window zawiera (73 funkcje)
Okna i Zarządzanie w Avoraiser
W tej sekcji znajdziesz wszystkie funkcje do tworzenia, manipulowania i stylowania głównych okien (oraz ich potomków) w frameworku Avoraiser.

 
Zarządzanie Oknami (Window Management)
Podstawowe operacje (Basics)

create_window  - Tworzy główne okno aplikacji na podstawie zdefiniowanych parametrów.

 PL:   utworz_okno  |  EN:   create_window 
Przykład użycia nazwa polska:

utworz_okno(parametry)

Przykład użycia nazwa angielska:
create_window(params)

Parametry nazwy angielskie:
ui_parameters params - Struktura parametrów okna (kolor tła, wymiary itp.).
Zwraca:   HWND - Uchwyt do utworzonego okna.

Dostępne parametry okna
params.title = 'Twoja Nazwa'     -  Tytuł okna
params = default(TAvocadoWindowParams)   - Resetuje wartości parametrów na standardowe 
    params.width = 400   - szerokość okna
    params.height = 600   - wysokość okna
    params.x = 200  - pozycja okna x
    params.y = 200  - pozycja okna y
    params.visible = true  - czy okno widoczne (true / false)
    params.allowmaximize = true   - Maksymalizacja okna (true /False) 
    params.allowdrag = true  - Przeciaganie okna za inne elementy okna (true /False) 
    params.frameless = True  -  Okno bez ramki nowoczesne UI (true /False)  
    params.BackgroundColor = $000000  - Kolor tła okna (BGR) lub można użyć konwersji na RGB - RGB(55, 96, 196)



    Parametry nazwy polskie:
parametry_ui params - Struktura parametrów okna (kolor tła, wymiary itp.).
Zwraca:   HWND - Uchwyt do utworzonego okna.

    Dostępne parametry okna
   params.tytul = 'Twoja Nazwa'     -  Tytuł okna
   params = default(TAvocadoWindowParams)  - Resetuje wartości parametrów na standardowe  
   params.szerokosc = 400   - szerokość okna
   params.wysokosc = 600   - wysokość okna
   params.x = 200 - pozycja okna x
   params.y = 200  - pozycja okna y
   params.widoczne = prawda  - czy okno widoczne (prawda / falsz)
   params.maksymalizacja = prawda   - Maksymalizacja okna (prawda / falsz) 
   params.przeciaganie = prawda   - Przeciaganie okna za inne elementy okna (prawda / falsz) 
   params.bezramkowe = prawda   - Okno bez ramki nowoczesne UI (prawda / falsz)  
   params.kolor_tla = $000000  - Kolor tła okna (BGR) lub można użyć konwersji na RGB - RGB(55, 96, 196)   


Przykład użycia nazwy polskie:
Tworzy główne okno w Avoraiser.
 avocado
program_ui test
import avoraiser.window
uchwyt_okna moje_okno
glowny
  glowna_funkcja
  uruchom_aplikacje()
koniec.
 
procedura glowna_funkcja
poczatek
  parametry_ui ui
  ui = default(TAvocadoWindowParams)
  ui.tytul = 'Okno w Avocado'
  ui.szerokosc = 400
  ui.wysokosc = 600
  ui.x = 200
  ui.y = 200
  ui.widoczne = prawda
  ui.maksymalizacja = prawda
  
  
  //Tworzenie Okna Main
  moje_okno = utworz_okno(ui)
  
  jezeli moje_okno <> 0 wtedy
  poczatek
    wysrodkuj_okno(moje_okno)
    //Kod aplikacji
   
  koniec
koniec   
 
Przykład użycia nazwy angielskie:
Tworzy główne okno w Avoraiser.
 avocado
program_ui test
import avoraiser.window
hwnd my_window
main
  my_win
  run_app
end.
 
procedure my_win
start
  ui_parameters ui
  ui = default(TAvocadoWindowParams)
  ui.title = 'Okno w Avoraiser - Avocado'
  ui.width = 400
  ui.height = 600
  ui.x = 200
  ui.y = 200
  ui.visible = true
  ui.allowmaximize = true
  
  
  //Creating a Window Main
  my_window = create_window(ui)
  
  if my_window <> 0 then
  start
    center_window(my_window)
    //Application code
   
  end
end
