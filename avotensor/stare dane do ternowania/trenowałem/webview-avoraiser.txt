  WebView (Przeglądarka Chromium / WebView2) w Avoraiser
Avoraiser zapewnia pełną, 100% integrację z silnikiem przeglądarki  CoreWebView2 (Chromium) . 

1. Tworzenie i Nawigacja

Silnik WebView2 automatycznie dopasowuje swój rozmiar (100% obszaru roboczego) do okna lub panelu, który wskażesz mu jako rodzica.

webview_create  - Inicjuje silnik przeglądarki wewnątrz wskazanego okna 
lub panelu. Przeglądarka automatycznie dopasuje się do wielkości rodzica.

 PL:   przegladarka_stworz  |  EN:   webview_create 

Parametry:
uchwyt_okna / h_wnd - Uchwyt okna lub panelu docelowego.
Przykład użycia nazwa polska:

 
przegladarka_stworz(uchwyt_okna)
webview_create(h_wnd)
// Przykład użycia z panelem:
my_panel := create_panel(MyWindow, 50, 50, 800, 600, RGB(151, 255, 234));
webview_create(my_panel);

Przykład użycia nazwa angielska:
webview_create(h_wnd)
// Przykład użycia z panelem:
my_panel := create_panel(MyWindow, 50, 50, 800, 600, RGB(151, 255, 234));
webview_create(my_panel);

webview_navigate  - Ładuje wskazaną stronę WWW w przeglądarce.
PL:   przegladarka_nawiguj  |  EN:   webview_navigate 
Parametry:
adres_url / url - Adres strony do załadowania.
Przykład użycia nazwa polska:
przegladarka_nawiguj(adres_url)
Przykład użycia nazwa angielska:
webview_navigate(url)
// webview_navigate('https://www.google.pl');

webview_navigate_to_string  - Zamiast pobierać stronę ze zdalnego serwera, renderuje lokalnie wstrzyknięty łańcuch z kodem HTML (np. offline wykresy, własne wygenerowane tabele).
 PL:   przegladarka_wczytaj_html  |  EN:   webview_navigate_to_string 
Parametry:
adres_url / html_content - HTML kod.
Przykład użycia nazwa polska:  
przegladarka_wczytaj_html(html_content)
Przykład użycia nazwa angielska: 
webview_navigate_to_string(html_content)

Brak parametrów

webview_execute_js  - Wstrzykuje i natychmiastowo wykonuje kod 
Wykonaj kod JavaScript (Wstrzyknięcie) 
Najpotężniejsza z funkcji do tworzenia botów i "skrobania" danych (Scraping). Pozwala zasymulować kliknięcia myszką przez skrypt, wypełnić formularz, wyciągnąć listę plików czy obejść blokady bezpośrednio w środowisku przeglądarki.

PL:   przegladarka_wykonaj_js  |  EN:   webview_execute_js 
Parametry:
kod_js / js_code - Kod JavaScript do wykonania.
Przykład użycia nazwa polska:
przegladarka_wykonaj_js(kod_js)
Przykład użycia nazwa angielska:
webview_execute_js(js_code)
// Przykład wyświetlający natywny alert strony:
// webview_execute_js('alert("Avoraiser przejął pełną kontrolę nad tą stroną!");')

4. Ograniczenia Interfejsu i Sterowanie Systemowe

Bardzo przydatne funkcje chroniące, np. przy tworzeniu zamkniętych "kiosków", by użytkownik nie otworzył przypadkiem kodu strony lub nie zapisywał plików prawym przyciskiem.

 PL:  przegladarka_ustaw_menu_kontekstowe|  EN:  webview_set_context_menu_enabled
Parametry:
  true / prawda - typ logiczny
  false / falsz - typ logiczny

Przykład użycia nazwa polska:
przegladarka_ustaw_menu_kontekstowe(prawda)
Przykład użycia nazwa angielska:

webview_set_dev_tools_enabled  - Zablokowanie / włączenie możliwości odpalenia "DevTools" i wstrzykiwania skryptów przez użytkowników skrótami klawiaturowymi.

 PL:  przegladarka_ustaw_narzedzia_dev|  EN:  webview_set_dev_tools_enabled

    Przykład użycia nazwa angielska:

webview_suspend  - Usypia silnik Chromium (Sleeping Tabs)
Przeglądarka Chromium zużywa dużo pamięci. WebView2 wspiera tzw. "Sleeping Tabs" (Usypianie Kart), uwalniając cenne zasoby procesora, gdy karta pracuje w tle. Kiedy okno znowu się pojawi na pierwszym planie, wystarczy wywołać obudzenie.

 PL:   przegladarka_uspij  |  EN:   webview_suspend 
    Parametry:
  Brak parametrów.
    Przykład użycia nazwa polska:
przegladarka_uspij()
Przykład użycia nazwa angielska:
webview_suspend
