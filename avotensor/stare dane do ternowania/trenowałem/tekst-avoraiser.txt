Pola Tekstowe (Text Controls)
Funkcje z rodziny Edit , Memo  oraz RichEdit  umożliwiają wczytywanie tekstu jedno i wielowierszowego oraz formatowania RTF.

 1. Edit (Jednowierszowe Pole Tekstowe)
create_edit 
 PL:  Utwórz pole tekstowe |  EN:  Create edit
Tworzy prosty komponent typu TextBox do wpisywania krótkich napisów bez tzw. "tłustej szarej ramki".
 pascal
create_edit(Parent: HWND; const Text: UnicodeString; X, Y, Width, Height: Integer): HWND;
 
set_edit_placeholder 
 PL:  Podpowiedź (Placeholder) |  EN:  Set edit placeholder
Ustawia tekst-wskazówkę znikającą po kliknięciu.
 pascal
set_edit_placeholder(hEdit: HWND; const PlaceholderText: UnicodeString; StayOnFocus: Boolean = True);
 
set_edit_alignment 
 PL:  Wyrównanie w poziomie |  EN:  Set edit alignment
Zmienia to czy wprowadzony napis ma być ułożony do lewej ( ES_LEFT ), do środka ( ES_CENTER ), lub do prawej ( ES_RIGHT ).
 pascal
set_edit_alignment(hEdit: HWND; Alignment: DWORD);
 

set_edit_vertical_center 
 PL:  Środek w pionie |  EN:  Set edit vertical center
Wyrównuje napis pionowo wewnątrz utworzonego okienka.
 pascal
set_edit_vertical_center(hEdit: HWND);
 

set_edit_color 
 PL:  Kolor pola |  EN:  Set edit color
Ustawia podstawowe kolory Edit .
 pascal
set_edit_color(hEdit: HWND; Color: COLORREF);
 

set_edit_focus_color 
 PL:  Kolor aktywnej ramki |  EN:  Set edit focus color
Oznacza Edit wybranym kolorem w chwili, gdy zyska Focus .
 pascal
set_edit_focus_color(hEdit: HWND; Color: COLORREF);
 

set_edit_password_char 
 PL:  Znak maskujący hasła |  EN:  Set edit password char
Maskuje litery (np. kropkami   lub gwiazdkami  ). Użycie znaku  0  wyłącza maskowanie.
 pascal
set_edit_password_char(Handle: HWND; C: WideChar);
 

   set_edit_numbers_only  - Blokuje pole Edit (TextBox) tak, aby użytkownik mógł wpisywać w nim wyłącznie cyfry.

 PL:  ustaw_w_polu_edycji_tylko_liczby  |  EN:  set_edit_numbers_only 
Parametry:
uchwyt_edycji / h_edit - Uchwyt pola Edit.
wlacz / enable - True  aby zablokować na same liczby, False  aby odblokować.

Przykład użycia nazwa polska:
ustaw_w_polu_edycji_tylko_liczby(uchwyt_edycji, wlacz)
Przykład użycia nazwa angielska:
set_edit_numbers_only(h_edit, enable)

set_edit_math_only 
 PL:  Tylko matematyka |  EN:  Set edit math only
Aktywuje tryb kalkulatora dla pola (akceptuje cyfry, kropki i znaki operatorów matematycznych).
 pascal
set_edit_math_only(h_wnd: HWND);
 

add_to_edit 
 PL:  Dopisz do edita |  EN:  Add to edit
Dopisuje ciąg znaków (Append) na koniec edita.
 pascal
add_to_edit(h_wnd: HWND; const text_to_add: UnicodeString);

PL:  Ustaw maksymalny limit znaków |  EN:  Set memo limit

set_memo_read_only  / set_control_read_only

is_memo_modified  / set_memo_modified 
 PL:  Czy treść uległa modyfikacji / Ustaw modyfikację |  EN:  Is memo modified / Set modified
Sprawdzenie, czy tekst uległ zmianom wewnątrz okienka - po to by spytać użytkownika przy wyjściu z aplikacji o konieczność zapisu edycji pliku na dysku.

   scroll_memo

   scroll_memo_to_caret

   scroll_memo_to_end

  3. RichEdit (Zaawansowane formatowanie RTF)

RichEdit to znacznie bardziej potężny zamiennik dla Memo. Pozwala na stylowanie poszczególnych partii tekstów (np. wytłuszczenie jednego wyrazu, barwienie drugiego na inny kolor itp.).

   create_rich_edit 
 PL:  Utwórz RichEdit |  EN:  Create rich edit
 pascal
create_rich_edit(Parent: HWND; X, Y, Width, Height: Integer): HWND;
 

   set_rich_text_text 
 PL:  Całkowite wczytanie RTF lub Unicode |  EN:  Set rich text text
Podmienia wszystko. Uwaga: wymazuje historię (Undo/Ctrl+Z) poprzednich wycofań.
 pascal
set_rich_text_text(handle: HWND; const text: UnicodeString);
 

   get_rich_text_text 
 PL:  Pobieranie pliku źródłowego RTF/tekstu z RichEdit |  EN:  Get rich text text
Wyciąga kod źródłowy z całego formatowania (w formacie tekstowym/Plain Text).

function get_rich_text_text(Handle: HWND): UnicodeString;
 

   set_rich_text_background_color

Ustawia podstawowy (statyczny) kolor całej kontrolki w locie.

   set_rich_text_color 
 PL:  Zmiana koloru zaznaczonego ciągu w RichEdit |  EN:  Set rich text color

   set_rich_text_bold  / set_rich_text_italic  / set_rich_text_underline 
 PL:  Zastosuj pogrubienie / Kursywę / Podkreślenie |  EN:  Set rich text bold / italic / underline
